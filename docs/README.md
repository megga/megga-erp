# Documents du chantier « Intendance »

Trois documents, sortis des sessions de conception et d'exécution. Ils ne sont
pas du code : ils disent ce qui a été décidé, pourquoi, et ce qu'il reste. En
cas de divergence avec le dépôt, **le dépôt fait foi**.

| Fichier | Ce que c'est |
|---|---|
| [`plan-inventaire-cabinet.html`](plan-inventaire-cabinet.html) | Le **plan d'exécution** des cinq chantiers (magasin, kits, réassort, matériel, stérilisation) et du regroupement sous « Intendance ». Décisions arrêtées, déroulé standard d'un chantier, et les pièges déjà payés. Page autonome : à ouvrir dans un navigateur. |
| [`prompt-claude-design-intendance.md`](prompt-claude-design-intendance.md) | Le **prompt pour Claude Design**, à coller tel quel. Autonome : il porte les vrais libellés, l'ordre réel des colonnes, les textes de refus mot pour mot et les données de démonstration — relevés dans le code, puis vérifiés contre lui. |
| [`plan-page-intendance.md`](plan-page-intendance.md) | Le **plan de la page** que ce prompt fait dessiner : le nom retenu, l'ossature en trois actes, et ce qu'on attend du designer. |

Les deux plans existent aussi en pages publiées, mais **ces fichiers-ci font
référence** : ils suivent le dépôt, donc les commits.
